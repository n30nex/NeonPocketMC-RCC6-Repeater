# RCC6 Ultimate Observer & Room Server v1.3.0 RC2

This experimental RCC6-L62/SX1262 release contains the Ultimate MQTT observer/repeater and all four Room Server profiles.

## Files

- Observer app and settings-preserving recovery image
- Minimal/full Room Server images in headless and NV3001B TFT variants
- Windows/Linux guided USB configurator
- Exact source/licenses and aggregate SHA-256 manifest

Normal updates use the selected app image at `0x10000`. Use a matching recovery image at `0x0` only for bootloader/partition recovery. Every recovery image stops before SPIFFS; never erase the whole chip.

## Location-advert correction

The full Web Config now displays the existing MeshCore advert-location policy beside saved latitude/longitude. Operators can explicitly share saved coordinates, remain private, or use a live external GPS source. Upgraded nodes retain their prior privacy setting until it is changed.

Minimal profiles have no Web Config and retain the proven USB CLI `gps advert none|share|prefs` control. Fresh repeater and Room Server identities continue to default to saved-coordinate adverts.

MQTT remains observation-only and never injects broker traffic into the mesh.
