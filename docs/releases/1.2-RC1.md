# RCC6 Ultimate Observer & Room Server v1.2.0 RC1

This experimental RCC6-L62/SX1262 release contains the Ultimate observer/repeater and all four Room Server profiles. Earlier releases remain available.

## Files

- `NeonPocketMC-RCC6-Ultimate-Observer-v1.2.0-rc.1-app.bin` — normal update at `0x10000`
- `NeonPocketMC-RCC6-Ultimate-Observer-v1.2.0-rc.1-full-recovery-preserves-meshcore-settings.bin` — bootloader/partition recovery at `0x0`
- `NeonPocketMC-RCC6-Ultimate-Room-Server-{minimal-headless|minimal-tft|full-headless|full-tft}-v1.2.0-rc.1-{app|full-recovery-preserves-meshcore-settings}.bin`
- `NeonPocketMC-RCC6-Ultimate-Server-v1.2.0-rc.1-configurator.zip` — Windows/Linux guided USB setup for the observer and full Room Server profiles
- `SHA256SUMS.txt` and the exact source/licenses bundle

Never erase the whole chip. Both supplied firmware images stop before the SPIFFS data partition.

## What is new

- A rebuilt RCC6 Ultimate dashboard with Overview, Mesh Map, Radio, MQTT, Network, and Console areas. The full Room Server profiles use the same dashboard with room-client and post metrics; the observer-only mesh map is hidden there.
- Operational-load bars for receive rate, transmit rate, and TX/RX channel airtime.
- Per-broker delivery bars with success/error counts alongside the existing detailed slot state.
- An offline map of directly heard repeater adverts carrying valid coordinates. Unlocated repeaters remain listed; the UI never guesses a position.
- Advertised repeater names and coordinates are retained in the 50-entry in-memory neighbor table for the dashboard. They are not written to identity/contact storage.
- Human-facing labels and descriptions replace implementation-heavy product copy.

The firmware uses official MeshCore 1.17.0 plus the relevant post-release SX126x boosted-RX-gain persistence fix. MQTT remains observation-only: broker traffic is not injected into the mesh.
