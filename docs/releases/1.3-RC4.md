# NeonPocketMC RCC6 Server Suite v1.3.0-rc.4

Experimental prerelease built from the exact tagged `main` commit and MeshCore 1.17.1.

- Saved-coordinate adverts work on GPS-less RCC6 observer and Room Server profiles.
- Old live-location settings migrate to saved-coordinate mode on GPS-less builds.
- GPS-capable regression targets retain live-GPS controls.

The release contains the observer, four Room Server profiles, guided configurator, exact source/licenses bundle, and checksums.
