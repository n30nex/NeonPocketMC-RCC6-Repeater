# NeonPocketMC RCC6 Server 1.1 RC1

Experimental combined release for the RCC6 MQTT observer/repeater and four Room Server profiles.

## Profiles

- Repeater/observer with Wi-Fi, two MQTT bridges, setup dashboard, and 3-byte advert hashes by default.
- Minimal Room Server, headless or TFT, with USB CLI and no Wi-Fi/MQTT stack.
- Full Room Server, headless or TFT, with authenticated AP/STA setup, dashboard, and one-way MQTT observation.

The full TFT profile uses an exact-color indexed framebuffer to retain a contiguous 32 KB post-service memory reserve. Every TFT profile keeps the 60-second screen timeout and raw battery-voltage warning.

## Install boundary

Normal application files are flashed at `0x10000`. Merged recovery files are flashed at `0x0` only when bootloader/partition recovery is required. Neither path writes the later SPIFFS data partition; never erase the whole flash for a normal update.

The release includes one layperson-oriented Windows/Linux configurator for the observer and full Room Server profiles. Minimal profiles are configured through USB CLI. Change both Room Server passwords before deployment.
