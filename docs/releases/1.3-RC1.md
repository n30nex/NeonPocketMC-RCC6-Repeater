# RCC6 Ultimate Observer & Room Server v1.3.0 RC1

This experimental RCC6-L62/SX1262 release contains the Ultimate observer/repeater and all four Room Server profiles. Earlier releases remain available.

## Files

- `NeonPocketMC-RCC6-Ultimate-Observer-v1.3.0-rc.1-app.bin` — normal update at `0x10000`
- `NeonPocketMC-RCC6-Ultimate-Observer-v1.3.0-rc.1-full-recovery-preserves-meshcore-settings.bin` — bootloader/partition recovery at `0x0`
- `NeonPocketMC-RCC6-Ultimate-Room-Server-{minimal-headless|minimal-tft|full-headless|full-tft}-v1.3.0-rc.1-{app|full-recovery-preserves-meshcore-settings}.bin`
- `NeonPocketMC-RCC6-Ultimate-Server-v1.3.0-rc.1-configurator.zip` — guided Windows/Linux USB setup for the observer and full Room Server profiles
- `SHA256SUMS.txt` and the exact source/licenses bundle

Never erase the whole chip. Both supplied firmware forms stop before the SPIFFS data partition.

## What changed

- Human-first Dashboard, Nearby, Radio, and MQTT language across desktop and mobile.
- Traffic mix and signal-distribution bars, neighbor freshness, and broker-health summaries.
- The Nearby map uses advertised coordinates only. Radios without coordinates stay visible in the directly-heard signal/recency view instead of receiving an invented location.
- Room Server neighbor telemetry now retains advertised names and coordinates in its fixed in-memory dashboard cache without modifying MeshCore identity or contacts.
- Selected reviewed observer fixes reduce per-slot MQTT memory, allocate clients and JWT buffers on demand, improve retry/reconnect timing, and reject invalid path encodings before serialization.

The firmware uses official MeshCore 1.17.0 plus the post-release SX126x boosted-RX-gain persistence fix. MQTT remains observation-only: broker traffic is not injected into the mesh.
