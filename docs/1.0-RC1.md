# 1.0 RC1

Initial experimental RCC6 MQTT repeater release.

## Included

- Headless Heltec RCC6-L62/SX1262 target.
- MeshCore 1.17.0 repeater behavior.
- Agessaman MQTT observer production source at `b744b42aabb454b277fe133214c7d93d23da484b`.
- First-boot Wi-Fi configuration portal.
- 34 built-in MQTT broker presets.
- Default active brokers `meshcore-ca-1` (`mqtt1.meshcore.ca`) and `meshcore-ca-2` (`mqtt2.meshcore.ca`).
- Application-update and full-recovery images with checksums.

## Qualification status

GitHub Actions compile and host-test results are release gates. Hardware validation is not yet claimed; this release remains a prerelease until an RCC6 unit proves Wi-Fi provisioning, both default MQTT connections, LoRa TX/RX, reset stability, and an idle run.
