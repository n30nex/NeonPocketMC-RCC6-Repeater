# 1.0 RC2

Experimental RCC6 MQTT repeater release focused on simple setup and management.

## Added

- Double-click Windows and one-command Linux USB setup launchers.
- Guided configuration of node name, complete regional radio preset, TX power,
  repeater mode, Wi-Fi, MQTT brokers, IATA region, and admin password.
- Saved-value verification, reboot monitoring, Web dashboard health check, and
  an explicit safe-to-disconnect result.
- Automatic authenticated LAN Web dashboard after Wi-Fi connects.
- Dashboard health badges, detailed counters, recent-neighbour list, per-broker
  status, and rolling packet/RF/airtime/queue/memory/power/Wi-Fi graphs.
- First-boot `MeshCore-Setup-XXXX` captive portal at `192.168.4.1`.
- Offline setup/help in the configurator ZIP, including dashboard IP discovery,
  login, DHCP reservation, Wi-Fi/MQTT troubleshooting, flashing, and recovery.
- Default 3-byte advert path hashes (`path.hash.mode 2`). Incoming packets using
  1-, 2-, or 3-byte path hashes continue to be forwarded.

## Preserved

- MeshCore 1.17.0 repeater behavior.
- All 34 agessaman observer MQTT presets.
- `mqtt1.meshcore.ca` and `mqtt2.meshcore.ca` defaults.
- Fail-closed MeshCore storage mounting.
- Application-update and recovery images that preserve the later SPIFFS data
  partition.

This release is for the Heltec RCC6-L62/SX1262 only.
